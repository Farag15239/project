HTML Uygulama 16: Canvas

Ana MenüUygulamalar
Kaynak kod:
<canvas id="grafik" width="420" height="180" style="border:1px solid #ccc;"></canvas>
<script>
const c = document.getElementById("grafik");
const ctx = c.getContext("2d");
ctx.fillStyle = "#7c3aed";
ctx.fillRect(30, 35, 90, 110);
ctx.fillStyle = "#0f766e";
ctx.fillRect(160, 65, 90, 80);
ctx.fillStyle = "#ea580c";
ctx.fillRect(290, 15, 90, 130);
</script>
Öğrenilen: JavaScript yardımıyla HTML canvas üzerinde basit bir grafik çizdim.
