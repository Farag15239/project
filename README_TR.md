# MEM215 – İnternet Tabanlı Programlama Ödev 2

Bu proje, ödev föyündeki iki bölümü kapsar:
- 20 HTML kısa uygulaması
- 20 CSS kısa uygulaması
- 20 Bootstrap kısa uygulaması
- Free Website Templates üzerindeki Space Science şablonundan esinlenerek hazırlanmış, tamamen özelleştirilmiş ana site
- Ana sayfa + 2 alt sayfa
- Her kısa uygulamanın altında Türkçe açıklama

Kaynak:
- W3Schools HTML, CSS ve Bootstrap örnekleri
- Free Website Templates – Space Science Template

Not: Şablonun kaynak kodundaki özgün kredi notlarının korunması ödev şartlarıyla uyumlu olacak şekilde `site/index.html` ve `site/css/style.css` içinde yorum olarak belirtilmiştir.
